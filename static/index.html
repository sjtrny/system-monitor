About these readings

GPU usage is the busiest engine class, averaged over the engines in that class. Video includes decoding and encoding. GPU memory is the sum of resident client allocations; shared buffers can be counted by more than one client. Very short GPU jobs between samples may be missed.

Memory usage excludes available RAM, including reclaimable cache. Disk traffic counts physical devices once. Filesystem capacities are independent; storage pools can overlap the disks listed below them. History starts when the collector starts.
